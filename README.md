矢部パン関屋店 — シンプルな静的サイト（仮）

このリポジトリの gh-pages ブランチに、矢部パン関屋店の簡易ホームページを追加しました。
画像はすべて同じ仮のイラスト（assets/illustration.svg）です。

公開方法:
- リポジトリの Settings → Pages で、ブランチに「gh-pages」を選択して保存してください。
- あるいは、GitHub Pages の設定で "gh-pages" ブランチを公開ルートに指定すると、https://<ユーザー名>.github.io/sekiya/ で公開されます。

編集:
- index.html を編集して営業時間や住所、写真に差し替えてください。
- images は assets/illustration.svg を差し替えると全体の仮画像を一括で変更できます。

ご希望があれば、実際のウェブ上の情報（住所、営業時間、写真）を反映して内容を更新します。
